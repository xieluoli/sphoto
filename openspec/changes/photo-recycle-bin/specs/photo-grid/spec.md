## ADDED Requirements

### Requirement: 展示全部图片的缩略图网格
获得相册权限后，应用必须以网格形式展示相册内全部图片的缩略图。

#### Scenario: 加载并排序
- **WHEN** 权限可用且完成加载
- **THEN** 按创建时间倒序（最新在前）展示所有 `PHAssetMediaType.image` 类型的资源

#### Scenario: 已在回收站的图片不出现
- **WHEN** 某张图片的标识已存在于回收站
- **THEN** 该图片不出现在网格中

#### Scenario: 相册为空
- **WHEN** 权限可用但可见图片数为 0
- **THEN** 展示空状态文案，不展示空白页

#### Scenario: 相册在应用外被修改
- **WHEN** 应用运行期间系统相册新增或删除了图片
- **THEN** 网格自动刷新到最新内容，且不因索引失效而崩溃

### Requirement: 点击缩略图进入大图
网格中的每个缩略图必须可点击并进入大图浏览页。

#### Scenario: 从被点击的那张开始看
- **WHEN** 用户点击网格中第 N 张缩略图
- **THEN** 大图页打开并显示第 N 张图片
