# photo-viewer Specification

## ADDED Requirements

### Requirement: 屏幕上的照片必须是当前这张
大图页每一页的视图身份必须由照片自身的资源标识决定，不得由它在列表中的位置决定。翻页或列表变化后，任一时刻屏幕上展示的图必须属于该位置当下的那张照片。

#### Scenario: 移入回收站后自动前进
- **当** 当前照片被移入回收站，可见列表整体前移，下一张顶到当前位置
- **则** 屏幕立刻展示新的当前照片，不得出现刚被移走那张的残留画面

#### Scenario: 连续翻页
- **当** 用户连续快速左右翻页
- **则** 每一页展示的都是它自己的照片，不出现上一张的残留画面

#### Scenario: 复用缩略图缓存作为首帧
- **当** 用户从网格点开一张照片
- **则** 首帧直接使用网格已缓存的缩略图，不先显示空白转圈

### Requirement: 翻页撤销已划走那页的取图请求
一页离开可见范围时，必须把它尚未完成的取图请求撤销到 PhotoKit，而不只是取消应用侧的异步任务。

#### Scenario: 快速连翻
- **当** 用户在取图尚未完成时连续翻过多页
- **则** 划走的页的请求被撤销，当前页的取图不被它们排队阻塞

#### Scenario: 被撤销的请求不改动界面
- **当** 一次取图请求因为页面划走而被撤销
- **则** 不得据此把该页判定为失败或改变它的下载控件状态
