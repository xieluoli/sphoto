# icloud-photo-download Specification

## ADDED Requirements

### Requirement: 缩略图只取本地版本
展示缩略图的请求必须禁止联网，只使用本地已有的版本。任何浏览动作都不得因为展示缩略图而触发 iCloud 下载。

#### Scenario: 网格滚动经过 iCloud 照片
- **当** 用户滚动网格，划过若干张原图只在 iCloud 的照片
- **则** 每个格子展示本地缩略图，且不产生任何 iCloud 下载

#### Scenario: 本地没有缩略图
- **当** 某张照片连本地缩略图都取不到
- **则** 该格子保持占位底色，不联网补取

### Requirement: 原图默认不自动下载
进入大图页时，取原图的请求必须禁止联网，只用于探测原图是否已在本地。原图仅在用户明确触发时才允许联网下载。

#### Scenario: 原图已在本地
- **当** 用户点开一张原图已在本地的照片
- **则** 先展示缩略图，随后自动替换为原图，且照片下方不展示任何下载控件

#### Scenario: 原图只在 iCloud
- **当** 用户点开一张原图只在 iCloud 的照片
- **则** 停留在缩略图，不发起下载，并在照片下方展示下载按钮

#### Scenario: 原图取不到且不在 iCloud
- **当** 探测原图时既没拿到图，也没被告知资源在 iCloud
- **则** 保持缩略图展示，不展示下载按钮（下载也拿不到东西）

### Requirement: 用户触发的 iCloud 下载
照片下方的下载控件必须反映下载的三种阶段：可下载、下载中、下载失败。

#### Scenario: 点击下载
- **当** 用户点击「从 iCloud 下载原图」
- **则** 控件立即变为下载中的 loading 提示，并发起允许联网的原图请求

#### Scenario: 下载完成
- **当** 允许联网的原图请求返回了图
- **则** 照片替换为原图，照片下方的下载控件消失

#### Scenario: 下载失败
- **当** 允许联网的原图请求因为网络或其他错误没拿到图
- **则** 控件变为可重试状态，用户可再次触发下载

#### Scenario: 下载中翻页离开
- **当** 用户在下载过程中翻到别的照片，使该页离开可见范围
- **则** 该次下载被撤销，不在后台继续消耗流量；该照片的控件回到可下载状态

### Requirement: 取图失败原因的判定
从 PhotoKit 回调判定失败原因时，必须区分「被取消」「资源在 iCloud」与「其他不可用」，且「被取消」的优先级最高。

#### Scenario: 请求被取消
- **当** 回调信息中标记了请求已取消
- **则** 判定为「被取消」，即使同时标记了资源在 iCloud 也不得判定为在 iCloud

#### Scenario: 资源在 iCloud
- **当** 回调信息中标记了资源在 iCloud，且未标记取消
- **则** 判定为「资源在 iCloud」

#### Scenario: 没有任何标记
- **当** 回调信息为空或不含上述任何标记
- **则** 判定为「其他不可用」
